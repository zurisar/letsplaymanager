📖 Руководство пользователя LetsPlayManager v0.8

LetsPlayManager — инструмент для летсплейщиков и контент-мейкеров, закрывающий рутину продакшена: учет проектов, пакетная нарезка Shorts, перепаковка сырых записей из OBS, генерация метаданных, планирование релизов и контроль загрузки на площадки.

📦 Установка и запуск

    Windows: Используйте установочный файл LetsPlayManager_Setup_v0.8.exe или распакуйте архив LetsPlayManager-v0.8-portable.zip в любую папку. Ручная установка FFmpeg не требуется — бинарники уже лежат в папке bin/ (ffmpeg.exe, ffprobe.exe). Данные программы хранятся в папке "Мои документы/LetsPlayManager"

    *Linux (nix): Поддерживается нативный запуск в среде Python 3.13+. Достаточно наличия системного ffmpeg, пакетов PyQt6 и стандартных зависимостей. Пути к системным утилитам подтягиваются автоматически. (Функциональность не проверена!) Данные программы должны хранится в /home/Documents/LetsPlayManager

⚙️ 1. Интерфейс, Профили и Темы

    Темная и светлая темы (Новое в 0.8): Полноценное переключение тем оформления без боли для глаз в ночных монтажных сессиях. Все элементы, подсказки и контрастность таблиц адаптированы под выбранную палитру.

    Мультиязычность: Полная поддержка локалей (Русский / English) с мгновенным переключением в настройках.

    Система профилей: Ведете несколько каналов? Создавайте независимые профили. Для каждого задаются аватар, базовые ссылки на соцсети и глобальный призыв к действию (CTA), автоматически попадающие в описания роликов.

    Настройка хостингов: Подключайте только актуальные площадки (YouTube, RuTube, VK Видео, Дзен) — главная таблица динамически перестраивается под выбранный набор чекбоксов.

🚀 2. Проекты, Метаданные и Шаблоны

    Игры и Steam: Добавление игры автоматически разворачивает файловую структуру проекта. По указанному Steam AppID подтягивается официальный постер и активируется кнопка запуска игры в один клик.

    Модульная система шаблонов (Новое в 0.8): Итоговый текст описаний собирается через конфигурируемые .tpl-шаблоны (папка Мои документы/LetsPlayManager/templates/{язык}/  файлы .tpl можно редактировать в обычном блокноте, список доступных тегов прилагается). Вы можете перестроить порядок блоков ссылок, таймкодов и тегов под свой стандарт оформления или использовать дефолтные пресеты.

    Метаданные серии vs Блокнот (notes.txt): Чистовые данные (уникальный заголовок, SEO-описание, таймкоды, теги) хранятся в базе данных и редактируются через окно метаданных с динамическим предпросмотром. Локальный текстовик переименован в notes.txt и служит быстрым черновиком для заметок.

    ИИ-ассистент с расчетом лимитов: Кнопка копирования промпта для нейросетей генерирует готовое ТЗ для ChatGPT/Claude с учетом контекста серии. Шаблон автоматически вычисляет допустимый остаток длины заголовка под жесткий лимит YouTube в 100 символов (max_title_len), скармливает ИИ таймкоды и формирует релевантные теги.

📱 3. Нарезка Shorts и Управление клипами

    Пакетная нарезка с нормализацией FPS (Новое в 0.8): Встроенный инструмент позволяет нарезать тяжелый исходник на вертикальные клипы по таймкодам. Доступен как мгновенный срез без перекодирования (режим stream copy), так и режим «Нормализация FPS», приводящий вариативный фреймрейт геймплейных записей к стабильному стандарту до импорта в видеоредактор.

    Быстрое копирование метаданных Shorts (Новое в 0.8): Менеджер шортсов позволяет не только отслеживать статус выгрузки по чекбоксам, но и в один клик копировать готовые метаданные (название, теги, описание) для каждого клипа.

    Умный архив: При очистке диска от тяжелых исходников завершенной игры проект можно перевести в «Архив», сохранив базу метаданных и еще не опубликованные Shorts.

📅 4. Расписание и Интерактивный Календарь (Обновлено в 0.8)

    Интерактивный календарь: Правая панель окна расписания оснащена живым календарем с цветовой разметкой дедлайнов:

        🟢 Зеленый день: Все запланированные на эту дату эпизоды полностью готовы (есть описание в БД и превью на диске).

        🔴 Красный день: На дату назначен выпуск, требующий доработки (Shorts не вызывают ложных срабатываний).

    Назначение серий в 2 клика: Двойной клик по любой дате в календаре открывает список выпусков без назначенной даты — выбираете серию, и график перестраивается на лету.

    Фокус на игре: Клик по строке серии в таблице расписания выделяет всю цепочку эпизодов конкретной игры и акцентирует даты их выхода в календаре. Повторный клик снимает фильтр.

🛠 5. Системные инструменты и Кодирование

    Автоматический Remux: Моментальная перепаковка сырых .mkv файлов из OBS в монтажный .mp4 без потерь качества и с автоопределением номера серии.

    Аппаратный транскодер: Встроенный энкодер видео с профилями битрейта под YouTube, архивное хранение (HEVC) и черновые превью с задействованием чипов NVENC / AMF.

    Фоновые обновления: Автопроверка релизов через GitHub API при старте с возможностью перехода к загрузке в один клик.
