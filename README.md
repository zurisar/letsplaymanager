📖 Руководство пользователя LetsPlayManager v0.5

LetsPlayManager — это удобный инструмент для геймеров и контент-мейкеров, создающих Let's Play видео и короткие вертикальные ролики. Программа помогает навести порядок в записях, автоматизировать перепаковку, управлять метаданными, планировать расписание выхода роликов и отслеживать статус выгрузки на видеохостинги.

⚙️ 1. Первоначальная настройка и Хостинги

При первом запуске программа предложит настроить базовые пути для автоматизации:

-  Папки: Укажите «Папку с исходниками» (куда пишет OBS) и «Папку с играми» (главная директория для отрендеренных проектов).
-  Пути к редакторам: Укажите исполняемые .exe файлы для текстового редактора (например, Notepad), графического редактора для превью (GIMP или аналог) и вашей основной монтажной программы (например, Magix Vegas Pro).
-  Управление видеохостингами: Вы можете добавлять новые колонки платформ (YouTube, RuTube, VK Видео) или удалять неактуальные. Таблицы перестроятся автоматически.

🚀 2. Управление проектами (играми)
-  Добавление игры: Нажмите «Добавить игру». При вводе названия автоматически сгенерируется путь внутри папки рендеров.
-  Интеграция ИИ: Укажите ссылку на диалог с нейросетью. Кнопка «🤖 ИИ-чат» на главной панели позволит мгновенно открывать этот диалог для генерации описаний или тегов.
-  Автосканирование: При выборе игры программа сканирует папку, находит директории вида ep1, ep2 и выводит эпизоды в таблицу.

🎮 Интеграция со Steam

Steam ID: При добавлении (или редактировании) игры вы можете указать её цифровой идентификатор из магазина Steam (например, 108600).

Умные кнопки: Если Steam ID указан, на главной панели появятся кнопки быстрого доступа: «🌐 Steam» (открыть страницу в магазине) и «🎮 Играть» (запустить игру напрямую через клиент Steam).

Автозагрузка обложек: Программа автоматически скачает официальную горизонтальную обложку игры (Steam Capsule) и положит её в главную папку игры под именем steam_capsule.jpg. Отлично подходит для оформления постов в соцсетях!

✏️ Редактирование и 🗑️ Удаление игр (Безопасность)

Безопасное переименование: При нажатии кнопки «Редактировать» вы можете изменить название игры, ссылку на ИИ или Steam ID. При этом физическая папка на диске не переименовывается, чтобы не сломать пути к исходникам в ваших старых проектах в видеоредакторе.

Удаление с защитой: Кнопка «Удалить игру» полностью очищает базу данных (включая шортсы и выгрузки) и удаляет папку со всеми видео с диска. Для защиты от случайных нажатий программа потребует вручную ввести точное название игры.

📊 3. Главная таблица эпизодов и Контекстное меню

Для каждого эпизода отображаются его параметры (размер, время), медиа-кнопки (открыть папку / запустить видео) и статус.

Дата публикации: Столбец для планирования выхода серий. Двойной клик вызывает интерактивный виджет календаря.

Контекстное меню (ПКМ): Клик правой кнопкой мыши по любой строке эпизода открывает меню быстрого доступа:
-  🔄 Обновить данные видеофайла: Полезно, если вы заменили отрендеренный видеофайл вручную. Программа заново пересчитает его вес и длительность.
-  📅 Изменить дату публикации: Вызов календаря.
-  🗑️ Удалить папку эпизода (Очистка): Безопасное удаление тяжелой папки эпизода с диска по завершении выгрузки. Запись в таблице останется и окрасится в голубой цвет.

🎨 4. Интеграция с редакторами (Описания и Превью)

В столбцах «Описание» (📝) и «Превью» (🖼️) находятся умные кнопки для создания текстовых файлов с SEO-метаданными и обложек:
-  🔴 Красная: Файл отсутствует на диске (нажмите, чтобы создать).
-  🟡 Желтая: Файл пустой или поврежден.
-  🟢 Зеленая: Файл готов к работе (нажмите, чтобы открыть в настроенном редакторе).

🌐 5. Управление загрузками и ссылками

Каждый добавленный видеохостинг представлен столбцом с чекбоксом публикации и умной кнопкой ссылки:
-  Карандаш (✏️): Нажмите, чтобы добавить ссылку на опубликованное видео.
-  Глобус (🌐): Появляется после сохранения ссылки. Левый клик открывает видео в браузере, а правый клик (ПКМ) позволяет изменить сохраненную ссылку.

📱 6. Менеджер шортсов (Shorts)

Колонка «Шортсы» в главной таблице показывает количество созданных коротких видео для каждого эпизода. 

Клик по кнопке («+ Добавить» или «Шортсов: X») открывает специализированный менеджер.

Верхняя панель: Содержит сводку по исходному эпизоду, кнопку «🎬 Видеоредактор» для быстрого запуска вашей программы монтажа и кнопку ИИ-чата.

Добавление файлов: Кнопка «+ Добавить готовый шортс» позволяет выбрать вертикальный ролик. Программа автоматически переместит его в подпапку shorts и переименует по стандарту (например, Игра - Ep.1 - Short 1.mp4).

Работа с метаданными: Двойной клик по ячейке «Теги» позволяет сохранить нужные хэштеги прямо в базу данных, без создания текстовых файлов.

Публикация: В таблице шортсов работает аналогичная система чекбоксов, календаря и умных кнопок-ссылок для отслеживания выгрузки на платформы.

🛠 7. Встроенные инструменты

Умное добавление эпизода: Кнопка под таблицей позволяет выбрать сырой .mkv файл из OBS. Программа автоматически определит номер серии и мгновенно перепакует видео в .mp4 без потери качества (remux), переместив его в папку нового эпизода.

Встроенный компрессор (Transcoding): Инструмент для сжатия видео с поддержкой аппаратного ускорения видеокарт и прогнозом итогового веса файла (идеально для платформ с жесткими лимитами на размер загрузки).📖
