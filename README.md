📖 Руководство пользователя LetsPlayManager v0.7

LetsPlayManager — это удобный инструмент для геймеров и контент-мейкеров, создающих Let's Play видео и короткие вертикальные ролики. Программа помогает навести порядок в записях, автоматизировать перепаковку, управлять метаданными, планировать расписание выхода роликов и отслеживать статус выгрузки на видеохостинги.

Для корректной работы программы больше не требуется ручная установка FFmpeg в систему. Распакуйте архив в удобное место. Убедитесь, что рядом с исполняемым файлом .exe находятся папки lang (файлы перевода) и bin (внутри должны лежать ffmpeg.exe и ffprobe.exe).

⚙️ 1. Базовая настройка и Профили (v0.7)

    Локализация и пути: В версии 0.7 добавлена полная мультиязычность — переключайте язык (Русский / English) прямо в настройках. Там же задаются папки исходников и рендеров, а также привязываются .exe файлы ваших видео и фоторедакторов.
    Система профилей (Новое!): Теперь можно создавать отдельные профили для разных каналов. Добавляйте аватарки, задавайте универсальные ссылки на соцсети и глобальные призывы к действию (CTA), которые будут автоматически подставляться под каждое видео.
    Управление хостингами: Гибко добавляйте нужные платформы (YouTube, RuTube, VK) или удаляйте лишние — главная таблица перестроится автоматически под ваши нужды.

🚀 2. Проекты, Метаданные и ИИ

    Игры и Steam: Добавление игры автоматически генерирует нужные папки. Укажите Steam ID для автозагрузки официальной обложки (Capsule) и появления кнопок быстрого запуска игры прямо из менеджера.
    Умный генератор метаданных (Новое!): Забудьте про ручные текстовики! Новое окно объединяет уникальные названия, описания, таймкоды и теги. Программа собирает итоговый текст с учетом шаблона игры и вашего профиля, предлагая кнопки мгновенного копирования адаптированного текста для Видео, Shorts или ИИ-промпта.
    Интеграция нейросетей: Привяжите ссылку на чат с ИИ к игре для быстрого доступа, а программа сама сгенерирует промпт с просьбой придумать кликбейтное название и SEO-теги на основе вашего описания серии.
    Умный архив: При удалении игры можно стереть только "тяжелые" исходники, оставив запись ради неопубликованных шортсов (режим Архива).

📱 3. Менеджер Shorts и Планировщик

    Массовая нарезка (Новое!): Встроенный инструмент позволяет задать несколько таймкодов (старт/длительность) и нарезать тяжелый исходник на шортсы пакетно, без пережатия (режим copy) и без необходимости открывать громоздкий видеоредактор.
    Управление Shorts: Отдельное окно для каждого эпизода позволяет привязывать готовые вертикальные ролики, хранить хэштеги в БД и отслеживать их статус выгрузки по чекбоксам.
    Календарь публикаций: Визуальная сетка для планирования выходов серий. Голубым цветом отмечаются уже вышедшие видео, желтым — запланированные, а двойной клик позволяет быстро изменить дату релиза.

🛠 4. Встроенные системные утилиты

    Автоматический Remux (Улучшено!): Быстрое добавление сырого .mkv файла из OBS. Программа сама определит номер серии и моментально перепакует видео в .mp4 без потери качества (в 0.7 исправлены баги с путями и расширениями файлов).
    Транскодер с профилями: Встроенное сжатие видео с поддержкой аппаратного ускорения (NVIDIA/AMD). Доступны готовые профили: «Черновик» (8 Mbps), «YouTube Optimal» (15 Mbps) и «Архив/Vegas» (HEVC, 30 Mbps) с расчетом итогового веса файла.
    Фоновое обновление: При запуске программа проверяет GitHub и ненавязчиво предлагает скачать новую версию, если она доступна.
