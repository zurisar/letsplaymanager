# 📖 Руководство пользователя LetsPlayManager v0.3

LetsPlayManager — это удобный инструмент для геймеров и контент-мейкеров, создающих Let's Play видео и не только. Программа помогает навести порядок в записях, автоматизировать перепаковку, управлять метаданными, превью и отслеживать статус выгрузки на видеохостинги.

## ⚙️ 1. Первоначальная настройка и Хостинги

При первом запуске программа предложит настроить базовые пути для автоматизации:

* **Папка с исходниками (OBS):** Директория, куда программа захвата сохраняет сырые видеофайлы.
* **Папка с играми (Рендеры):** Главная папка, внутри которой будут создаваться папки для каждого отдельного проекта (игры).
* **Управление видеохостингами:** В настройках вы можете добавлять новые колонки (например, *VK Видео*, *Дзен*) или удалять неактуальные. Таблица на главном экране перестроится автоматически.

## 🚀 2. Управление проектами (играми)

* **Умное добавление игры:** Нажмите «Добавить игру». При вводе названия программа автоматически сгенерирует путь внутри папки Рендеров. Вы также можете указать уже существующую папку вручную с помощью кнопки «Обзор».
* **Интеграция ИИ:** При добавлении игры можно сразу указать ссылку на диалог с нейросетью (для генерации описаний, тегов).
* **Панель инструментов:** Под списком игр находится панель управления текущим проектом. Кнопка **«🤖 ИИ-чат»** позволяет мгновенно открыть привязанный диалог в браузере (или привязать его, если ссылка еще не задана).
* **Автосканирование:** При выборе игры программа автоматически сканирует папку, находит директории вида ep1, ep2 и т.д., и добавляет новые эпизоды в базу данных.



## 📊 3. Таблица эпизодов и медиа

Для каждого эпизода программа отображает в таблице ключевые параметры:

* **Эпизод и кастомное название:** В первом столбце отображается номер серии. Двойной клик по названию позволяет добавить собственную подпись (например, — чиним подвеску).


* **Размер и длительность:** Автоматически считываются с видеофайла (.mkv, .mp4) и кэшируются в базе данных.


* **Медиа-панель:** Кнопка 📁 мгновенно открывает папку конкретного эпизода в Проводнике, а кнопка ▶️ запускает готовое видео в вашем плеере по умолчанию.
* **Цветовая индикация диска:** Если исходные видеофайлы с диска были удалены (через функцию очистки), строка подсвечивается голубым цветом с подсказкой.



## 🎨 4. Интеграция с редакторами (Описания и Превью)

* **Описание:** текстовый файл с названием видео для видеохостинга и описанием, включая хештеги и прочее.


* **Превью:** картинка для видео (обложка).


* **Редакторы:** Редактор по умолчанию для текстовых файлов Notepad. Редактор по умолчанию для картинок GIMP. Вы можете использовать любой другой удобный для вас редактор (просто в надписях будет упоминаться GIMP, но указать можно любой exe файл).



В столбцах «Описание» (📝) и «Превью» (🖼️) находятся компактные умные кнопки с цветовой индикацией:

* 🔴 **Красная:** Файл (desc.txt или preview.jpg) отсутствует на диске (нажмите, чтобы создать/добавить).


* 🟡 **Желтая:** Файл пустой или поврежден.


* 🟢 **Зеленая:** Файл на месте и готов к работе (нажмите, чтобы открыть в текстовом редакторе или GIMP).



## 🌐 5. Управление загрузками и ссылками

Каждый добавленный вами видеохостинг представлен в таблице отдельным столбцом с тремя элементами:

* **Чекбокс:** Отмечает факт публикации видео.


* **Карандаш (✏️):** Открывает диалоговое окно для ввода/изменения прямой ссылки на опубликованный ролик.
* **Глобус (🌐):** Появляется после сохранения ссылки и позволяет открыть опубликованное видео прямо в браузере.

## 🛠 6. Полезные инструменты

* **Умное добавление эпизода:** Кнопка «Добавить эпизод» позволяет выбрать исходный видеофайл и автоматически определяет следующий номер серии.
* **Для .mkv (Remux):** Файл быстро перепаковывается в .mp4 без потери качества (-c copy). При записи в OBS лучше записывать видео в mkv контейнер, так как при внезапных сбоях (отключение электричества, зависание ПК и т.п.) файл в формате mkv выживет, а его можно будет использовать равно до момента остановки записи, тогда как файл в mp4 формате может повредиться так, что его не возможно будет использовать. Однако для загрузки видео на видеохостинги, нужно видео в формате mp4.


* **Для готовых .mp4 (после монтажа):** Галочка перепаковки снимается автоматически, и программа просто переносит/переименовывает файл в папку эпизода.


* **Встроенный компрессор (Transcoding):** Инструмент для сжатия видео с поддержкой аппаратного ускорения (видеокарты AMD/NVIDIA) и прогнозом итогового веса файла. Подойдет при ограничениях на размер файла для загрузки, кодирует одним из 5 предустановленных кодеков.


* **Очистка старых исходников:** Безопасное удаление тяжелых файлов с диска по завершении монтажа с предварительным выбором эпизодов. Удаляет не исходные файлы, а сами папки с эпизодами! Исходные файлы программа не трогает.
