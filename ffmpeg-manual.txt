!!! ВНИМАНИЕ !!! Для правильной работы программы требуется установленный FFmpeg!
А так же его необходимо добавить в PATH!

🛠 Инструкция по установке FFmpeg и добавлению в PATH
Шаг 1. Скачивание FFmpeg

    Перейдите на официальный сайт загрузки FFmpeg для Windows: gyan.dev/ffmpeg/builds.

    Прокрутите страницу до раздела release builds и скачайте архив ffmpeg-release-essentials.zip (или ffmpeg-git-essentials.zip).

Шаг 2. Распаковка архива

    Распакуйте скачанный ZIP-архив.

    Внутри будет папка с длинным названием (например, ffmpeg-7.0-essentials_build или аналогичная). Переименуйте её просто в ffmpeg.

    Переместите эту папку в корень вашего системного диска (обычно это диск C:\). В итоге у вас должен получиться путь: C:\ffmpeg.
    (Важно, чтобы внутри этой папки сразу лежала папка bin, в которой находится файл ffmpeg.exe).

Шаг 3. Добавление FFmpeg в переменные среды (PATH)

Чтобы операционная система (и наша программа LetsPlayManager) знала, где искать FFmpeg, его нужно прописать в системный путь:

    Нажмите клавишу Windows на клавиатуре, начните писать «Переменные среды» и выберите пункт «Изменение переменных среды системы».

    В появившемся окне нажмите кнопку «Переменные среды...» в правом нижнем углу.

    В нижней части окна («Системные переменные») найдите переменную с именем Path (или PATH), выделите её и нажмите кнопку «Изменить...».

    В открывшемся списке нажмите кнопку «Создать» справа и введите путь к папке bin:
    Plaintext

    C:\ffmpeg\bin

    Нажмите «ОК» во всех открытых окнах настройки переменных среды, чтобы сохранить изменения.

Шаг 4. Проверка установки

    Откройте командную строку (нажмите Win + R, введите cmd и нажмите Enter).

    Введите команду:
    Bash

    ffmpeg -version

    Если всё сделано правильно, в консоли появится информация о версии FFmpeg, списке компонентов и кодеках, вместо ошибки «команда не найдена».
